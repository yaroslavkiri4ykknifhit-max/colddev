# Аналитика

| Источник | Текущее состояние | Как получить данные |
| --- | --- | --- |
| Google Search Console | Нет подключённого отчёта по проекту | В подтверждённом ресурсе colddev.pro выгрузить Эффективность → Поиск → страна Беларусь, запросы и страницы за последние 28 полных дней. Для индексации использовать отчёт по страницам и проверку URL. |
| Яндекс Вебмастер | Нет подключённого отчёта | Подтвердить сайт, отправить sitemap.xml, выгрузить статистику запросов и посмотреть индексирование. |
| Google Keyword Planner | Измерений не получено | Выгрузить ключевые слова с географией Беларусь и периодом, сохранить диапазон/значение, конкуренцию Google Ads и параметры. |
| Яндекс Wordstat | Измерений не получено | Авторизоваться, выбрать регион Беларусь и выгрузить значения с датой и видом совпадения. |
| Google Trends | Относительная динамика, стартовый замер не зафиксирован | Использовать при достаточном объёме для сезонности. Хранить нормализованный индекс с периодом и регионом. |
| GA4 / Метрика | Счётчики в коде не обнаружены | После согласования подключить выбранную аналитику. Различать клик в Telegram, клик по телефону и подтверждённое обращение. |

CTR = клики / показы для одного источника и среза. Для истории вести дату, период, поисковую систему, страну, тип поиска, страницу или запрос, показы, клики, CTR, позицию и источник. Отчёт по сайту хранить отдельно от наблюдений по рынку.
