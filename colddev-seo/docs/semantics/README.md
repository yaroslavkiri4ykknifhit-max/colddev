# Поисковые данные

- queries.csv — дедуплицированные формулировки. Сохранять идентификаторы существующих строк при обновлении. Пробелы, регистр и ё/е нормализуются для поиска дублей.
- measurements.csv — наблюдения по источникам. Порядок подсказки — место в ответе Autocomplete. Объём и конкуренция пусты, пока их не измерит отдельный источник.
- sources/ — сохранённые исходные списки подсказок и выборки из браузера без рекламных трекинговых ссылок. Подсказки собраны по 9 фразам в каждой системе. География передана параметром, но геозависимость результатов не подтверждена независимо.
- serp-results.csv — сохранённые органические результаты из Chrome. Порядок относится к извлечённой выборке. Промежуточные блоки, видео и карты учитывайте при анализе намерения. Снимок может зависеть от сессии, региона и времени.
- clusters.csv и semantic-map.csv — предварительная привязка. Для проверки сравнивайте канонизированные URL двух запросов внутри одной поисковой системы и региона, на одинаковой глубине. Запишите долю общих URL и тип страниц, затем проверьте смысл вручную. Строки research остаются без коммерческой посадочной.

В этой итерации очищены вакансии, обучение, явно нерелевантные страны, чужие бренды и устаревшие годовые варианты. Примеры из двух источников объединяются по строке, но каждое наблюдение остаётся в measurements.csv.
