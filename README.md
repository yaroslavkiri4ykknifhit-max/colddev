# COLDDEV

Статический сайт digital-студии: сайты, контекстная реклама, автоматизация, портфолио и контакты. Next.js экспортирует готовые HTML, CSS, JavaScript и медиа для GitHub Pages. Сервер и внешняя база данных не нужны.

## Разработка

```bash
npm ci
npm run dev
```

## Проверка и публикация

```bash
npx tsc --noEmit
npm run build
```

Push в `main` запускает `.github/workflows/deploy.yml`: сборка `out/` публикуется в `gh-pages`. Сохраняются `CNAME` (`colddev.pro`) и `.nojekyll`. Публикация заменяет содержимое ветки, поэтому старые страницы также удаляются.

## Контент

- Главная: `src/app/page.tsx`.
- Портфолио: шесть проектов в `src/lib/cases.ts`; превью в `public/work/`. Карточки ведут напрямую на сайты проектов. `/cases/` — самостоятельная страница портфолио, старые ссылки с query-параметрами тоже открывают этот список.
- Личный сертификат Ярослава Киричука Google Ads Search: `src/components/GoogleAdsCertificate.tsx`. Карточка находится в блоке опыта перед кейсами; из первого экрана на неё ведёт ссылка. Проверка: https://skillshop.credential.net/6c2111d9-d037-44cd-8c4a-0b58b9592165. Выдан 19.10.2026, действует до 19.10.2027. Оригинальный знак сохранён в `public/certificates/google-ads-search-badge.png` со страницы сертификата (https://templates.images.credential.net/16692030476507846323162302235838.png).
- Показатели: 2 года опыта, 43 успешных проекта и 316 500 BYN выручки клиентов благодаря нашей работе — данные владельца сайта в `src/config/site.ts`. `CountUp.tsx` запускает счётчики один раз при появлении в области просмотра и разделяет разряды пробелом; при уменьшении движения показывает итог сразу. Выручка клиентов не обозначается как прибыль или доход студии.
- `ClientsMarquee.tsx`: непрерывная лента компаний справа налево, с паузой по кнопке, наведению и фокусу. При уменьшении движения — статичный список.
- Тарифы: сайт от 899 BYN, Яндекс Директ от 399 BYN, Google Ads и автоматизация — по расчёту. Рекламный бюджет отдельно.
- Контакты, реквизиты и метаданные: `src/config/site.ts`. Телефон и Telegram — прямые ссылки; имя и УНП указаны владельцем.
- Стили: `src/app/globals.css`.
- Локальный шрифт Onest. Сайт не загружает шрифты с внешних сервисов.
- `public/media/norma-grab-scroll.mp4` — видеодеталь с рукой и диском, добавленная по прямому запросу владельца сайта. Источник: https://nor.ma/ (https://pub-a39f2798fdf6474e8442240e34642b65.r2.dev/reveal/norma-grab.mp4). Видео хранится локально и заранее загружается рядом с блоком. Видео находится справа от заголовка первого экрана (на телефоне — под текстом). На компьютере первый блок закрепляется; на телефоне он прокручивается обычно, а кадр зависит от положения видео в видимой области. Позиция прокрутки связана с `currentTime`: остановка фиксирует кадр, обратная прокрутка перематывает назад. Обычного воспроизведения и таймера нет. Для плавного поиска кадров используется H.264 с ключевым кадром каждые три кадра; при системном уменьшении движения показывается статичный постер без закрепления. Постеры взяты из исходного видео.

Сайт не использует Google Sheets, Google Identity, Apps Script, cookies, localStorage или отправку форм. Личный контакт открывается в Telegram или по телефону. Не публикуйте в портфолио показатели, отзывы и число клиентов без подтверждения.
