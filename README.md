# COLDDEV

Статический сайт digital-студии: сайты, контекстная реклама, портфолио и контакт в Telegram. Next.js экспортирует готовые HTML, CSS, JavaScript и медиа для GitHub Pages. Сервер и внешняя база данных не нужны.

## Разработка

```bash
npm ci
npm run dev
```

## Проверка и публикация

```bash
npx tsc --noEmit
npm run build
```

Push в `main` запускает `.github/workflows/deploy.yml`: сборка `out/` публикуется в `gh-pages`. Сохраняются `CNAME` (`colddev.pro`) и `.nojekyll`. Публикация заменяет содержимое ветки, поэтому старые страницы также удаляются.

## Контент

- Главная: `src/app/page.tsx`.
- Портфолио: шесть проектов в `src/lib/cases.ts`; превью в `public/work/`. Карточки ведут напрямую на сайты проектов. `/cases/` — самостоятельная страница портфолио, старые ссылки с query-параметрами тоже открывают этот список.
- Контакты и метаданные: `src/config/site.ts`.
- Стили: `src/app/globals.css`.
- Локальный шрифт Onest. Сайт не загружает шрифты с внешних сервисов.
- `public/media/norma-grab.mp4` — видеодеталь с рукой и диском, добавленная по прямому запросу владельца сайта. Источник: https://nor.ma/ (https://pub-a39f2798fdf6474e8442240e34642b65.r2.dev/reveal/norma-grab.mp4). Видео хранится локально; загружается при появлении блока на экране, воспроизводится без звука один раз, поддерживает повтор и системное уменьшение движения. Постер — кадр исходного видео.

Сайт не использует Google Sheets, Google Identity, Apps Script, cookies, localStorage или отправку форм. Личный контакт открывается в Telegram. Не публикуйте в портфолио показатели, отзывы и число клиентов без подтверждения.
